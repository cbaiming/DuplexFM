# PairAC 直接拼接架构

## 来源任务：miRNA–mRNA interaction

guide保留真实长度，target真实长度不超过60，居中补PAD至60；PAD不是碱基，也不是低反应性值。真实输入只接受ACGU，排除未知碱基。

交互图形状为 `[batch, channel, guide_position, target_position]`，总16通道：

|通道|含义|
|---|---|
|0:4|16种有方向的ACGU碱基对，共享4维可学习查表，共64参数|
|4:12|guide/target公共编码器+fresh LoRA+在线投影产生的8头Q/K相似度，经过有界变换|
|12|冻结的target逐碱基结构反应性代理|
|13|反应性减去7nt有效局部背景均值|
|14:16|guide与target坐标|

配对查表对所有guide×target位置计算，不是已知匹配点位、结合概率或seed类别。
target使用mRNABERT、guide使用RNA-FM，原公共参数冻结，fresh LoRA及任务投影参与miRNA训练。
开放性预测器不在来源联合训练图内，使用单独冻结缓存；不应称为校准开放概率。

16通道直接拼接 → 1×1投影到32 → 三个局部残差卷积块（dilation 1/1/2）。
随后沿反平行候选对齐聚合，按guide的2–8、9–12、1及13之后三个位置区间各做mean/max。
每个候选为 `3×2×32=192` 维，再编码64维，候选注意力聚合，输出二分类logit。
miRNA扫描可行的整个窗口；并不强制结合点位在中央。

不含BIO/Inta和手工乘积，但仍有公共预训练、位置、反平行对齐与卷积局部性先验，不能称完全无先验。

## siRNA迁移

冻结上述来源模型。guide19、target57在输入时补至60；设计核心为原target索引19:38。
提取特定设计位点的192维表示，不使用miRNA分类分数。测试有单独的手工反平行池化复算。

当前实用读出是 **TD24 + source192 = 216维**，不是旧PCA16/44维读出，也不是基模型预测堆叠。
R55按训练折拟合尺度，source尺度有1%中位标准差下限并除以sqrt(12)。
对target25相似组建模训练期惩罚截距，惩罚rho=n/K；source系数视为6×32矩阵并施加trace/nuclear-norm惩罚。
五个alpha固定0.1、1、10、100、1000，由内层OOF PCC、MSE和更强正则平局规则选择。
最终部署仅使用线性系数与全局截距，不输入未知测试组的偏移。该目标不是普通Ridge，应直接检查round55/head.py及独立数学证书。

历史round目录仅是实际依赖位置。部分模块含以前未调用的PCA等函数：当前readout只调用scaler/score、round55求解器等明确接口，不能因文件名判断当前使用PCA。

## 消融

原形状和初始化配对保留；分别将pair4、cross8或access2通道置零。坐标2通道保留。
屏蔽分支无有效梯度，但参数外形与有效学习容量不同。Full没有expert gate，因此这里不存在“把gate也置零”的操作。
历史seed42与seed43/44分别训练、分别保存协议，未按最佳测试种子挑选。
