# 建议合作者检查的问题

这是一份已执行实验的代码快照，不预设审查应当得到正面结论。

1. **坐标与掩码**：CLS/SEP不进入碱基图；中心PAD与真实坐标分开；guide方向及siRNA设计位点反平行索引正确；卷积前后和mean/max池化不泄漏PAD。
2. **配对表示**：16种有方向碱基对的ID、共享位置查表和梯度正确。避免将embedding理解成配对概率。
3. **Cross与参数更新**：公共权重是否被完整加载、仅LoRA及任务层更新、Q/K计算图是否在线；fresh LoRA B是否为0；混合精度、gradient accumulation与global batch是否一致。
4. **开放性**：缓存来源冻结且独立；局部背景只覆盖真实位置；no_access是否同时屏蔽原值与局部差值。
5. **消融**：完整模型与各消融的相同种子初始参数一致；只屏蔽目标通道；关闭分支不会改变其他输入；区分参数外形相同与有效容量相同。
6. **来源训练**：固定terminal、32728更新，不能以测试集选择epoch；来源keep-overlap是已知限制，不是独立无泄漏验证。
7. **迁移**：只冻结表示，不读取来源分类分数；TD24和source仅按fit归一；inner fit/val、outer test严格区分；trace约束、组截距消元、证书与部署系数回代一致。
8. **可复现与恢复**：保存optimizer、RNG、数据游标；同一锁下恢复；原子checkpoint、已知备份竞争修复、预算累计和失败费用；不得用删除STOP或清空ledger来规避恢复检查。
9. **效率**：tokenizer和设备拷贝开销、有效batch和CPU线程、重复编码、source192池化；若重构请先验证数值与梯度等价，再重新评价性能。

已知边界：没有随包附真实数据、预训练权重、划分ID及原运行锁。合成测试通过仅支持代码局部行为，不证明公共编码器、完整训练、泛化性能或因果机制成立。
近期多轮模型选择使用过这些开发数据；四个siRNA设置实际上只有三个唯一队列，Huesken→Mixset不是第四个独立数据集。
来源上下文暴露、source keep-overlap与gene/assay层面隔离限制需要另看实验审计。

如果发现问题，请记录文件/函数、触发条件、最小合成复现和可能影响的结论。不要仅用gate权重或单次seed的变化推断专家必要性。
